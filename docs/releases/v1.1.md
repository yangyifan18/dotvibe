# dotvibe v1.1 Release Notes

dotvibe v1.1 makes the project easier to install, validate, and use from coding agents.

## Highlights

- Homebrew install is live:

```bash
brew install yangyifan18/tap/dotvibe
```

- Agent-assisted export/import is now documented through the Codex `dotvibe-migration` skill, including natural-language prompts such as `调用 dotvibe 导出记忆` and `调用 dotvibe 导入旧 Mac 的记忆`.
- Project relocation planning supports changed home paths, missing project clone suggestions, existing project memory review, and remote mismatch review signals.
- The v1.1 README now positions dotvibe as AI coding context migration across machines and environments, not just new-Mac backup.
- A local Homebrew preflight harness validates dotvibe inside fake source and target homes before formula changes ship.

## Validation

Checked on 2026-06-03:

- `brew install yangyifan18/tap/dotvibe` passed.
- `dotvibe --version` printed `dotvibe version 1.1`.
- `brew test yangyifan18/tap/dotvibe` passed.
- The Homebrew-installed binary passed the full functional preflight:

```bash
./scripts/homebrew-preflight.sh --binary "$(brew --prefix dotvibe)/bin/dotvibe" --keep
```

The preflight covers `status`, `agent doctor/inventory/import-plan`, `export/list`, privacy exclusions, `import --dry-run`, `import --stage`, direct fake-HOME import, incremental diff, recipe export/lint/apply/rollback, and `setup` dry-run.

Tap CI run `26806025769` passed on `macos-26`, `macos-15-intel`, and `ubuntu`.

## Known limitations

- Homebrew currently installs from source; bottles are not published yet.
- The Homebrew smoke test writes to the real Homebrew prefix, so keep using fake HOME preflight for dotvibe data safety and a clean macOS VM for stronger release isolation.
- GitHub Actions may show a Node 20 deprecation annotation from third-party action dependencies; it is not a dotvibe runtime failure.
